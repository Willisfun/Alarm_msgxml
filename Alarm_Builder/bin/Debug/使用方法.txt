============================================================
                 KAFO Alarm Builder 使用說明
============================================================

【功能】

本工具可依據 Excel 警報資料，自動完成以下工作：

．產生 Symbol 訊息檔
    *_symbol.msgxml

．產生 Comment 訊息檔
    *_comment.msgxml

．同步修改 FANUC PICTURE XML，
  將 Alarm 畫面連結至新的 msgxml 檔案。


============================================================
【使用步驟】
============================================================

Step 1.
點擊【開啟 XML 檔案】

選擇 FANUC PICTURE Alarm XML。


Step 2.
點擊【開啟 Excel 檔案】

選擇警報資料 Excel。


Step 3.
輸入【輸出檔名】

例如：

Alarm

將產生：

Alarm_symbol.msgxml
Alarm_comment.msgxml


Step 4.
點擊【開始建置】

完成後將自動：

✓ 產生 msgxml
✓ 修改 XML 參考路徑


============================================================
【輸出位置】
============================================================

所有 msgxml 將輸出至：

VtsData

資料夾。

並同步更新 XML 中的 msgxml 名稱。


============================================================
【Excel 格式說明】
============================================================

Excel 第一列為標題，資料由第二列開始讀取。

欄位格式如下：

┌──────┬─────────────────────────────────────┐
│ 第一欄 │ ADDRESS                           │
│        │ PLC Alarm 位址                   │
│        │ 例如：A24.0、A24.1               │
├──────┼─────────────────────────────────────┤
│ 第二欄 │ SYMBOL                            │
│        │ Alarm 代碼                       │
│        │ 例如：SPINDLE_STOP               │
├──────┼─────────────────────────────────────┤
│ 第三欄 │ COMMENT                           │
│        │ Alarm 內容                       │
├──────┼─────────────────────────────────────┤
│ 第四欄 │ (保留)                            │
├──────┼─────────────────────────────────────┤
│ 第五欄 │ KeepFormat（選填）               │
│        │ 空白：自動整理 COMMENT 格式      │
│        │ 有任何內容：保留 Excel 原始格式  │
└──────┴─────────────────────────────────────┘

本工具會依據工作表名稱，自動判斷輸出的語言：

工作表名稱              輸出內容
------------------------------------------------
中文                   完全等於「ALARM」
英文                   名稱包含「EN」
簡體中文               名稱包含「簡」

例如：

ALARM
ALARM_EN
ALARM_簡

皆可正確辨識。


============================================================
Excel 範例
============================================================

ADDRESS     SYMBOL           COMMENT                KeepFormat
-----------------------------------------------------------------------
A24.0       SPINDLE_STOP     主軸停止
A24.1       LUBE_LOW         潤滑油不足
A24.2       DOOR_OPEN        安全門開啟            Keep

============================================================
注意事項
============================================================

1. ADDRESS 必須符合 PLC 位址格式（例如 A24.0）。

2. SYMBOL 為 Alarm 代碼，不可重複。

3. COMMENT 為對應語言的 Alarm 內容。

4. 若 COMMENT 留白，將保留原 msgxml 的內容，不會覆蓋。

5. KeepFormat 為選填欄位。
   若第五欄為空白，COMMENT 將自動整理文字格式；
   若第五欄填入任何內容，COMMENT 將保留 Excel 原始格式。
